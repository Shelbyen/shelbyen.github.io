## 2. Обработка пропусков

### 2.1 Столбцы с пропусками

df.columns[df.isna().any()]
```
```
Index(['Age', 'Cabin', 'Embarked'], dtype='object')

### 2.2 Обработка столбца `Age`

**Метод:** заполнение медианным значением — лучший выбор по сравнению со средним, так как менее чувствителен к выбросам.

```python
age_mean = df["Age"].mean()    # 29.699
age_median = df["Age"].median() # 28.0

df["Age"] = df["Age"].fillna(age_median)
```

Среднее значение возраста: **29,70**, медианное: **28,0**. Незначительная разница подтверждает умеренную правую асимметрию.

После заполнения создан новый признак `Age_group`:

```python
def age_group(age):
    if age < 12:    return "Child"
    elif age < 18:  return "Teen"
    elif age < 35:  return "YoungAdult"
    elif age < 60:  return "Adult"
    return "Senior"

df["Age_group"] = df["Age"].apply(age_group)
```

### 2.3 Обработка столбца `Embarked`

**Метод:** заполнение модой (наиболее частым значением).

```python
embarked_mode = df["Embarked"].mode()[0]  # 'S'
df["Embarked"] = df["Embarked"].fillna(embarked_mode)
```

Порт Southampton (`S`) является наиболее распространённым и был использован для заполнения 2 пропусков.

### 2.4 Обработка столбца `Cabin`

Из-за большой доли пропусков (77%) прямое заполнение нецелесообразно. Вместо этого из каждого значения извлекается **первая буква**, кодирующая палубу. Пропуски помечаются как `"Unknown"`:

```python
df["Cabin_letter"] = df["Cabin"].str[0].fillna("Unknown")
```

Итог: новый признак `Cabin_letter` принимает **9 уникальных значений** (A–G, T и Unknown), что позволяет сохранить часть информации о местоположении каюты.

## 3. Трансформация данных

### 3.1 Преобразование `Pclass` в категориальный тип

```python
pclass_map = {1: "F", 2: "S", 3: "T"}
df["Pclass"] = df["Pclass"].map(pclass_map).astype("string")
```

Классы переименованы: **F** (First), **S** (Second), **T** (Third).

### 3.2 Извлечение признака `Title` из имени

```python
def extract_title(name):
    m = re.search(r",\s*([^\.]+)\.", name)
    return m.group(1).strip() if m else "Unknown"

df["Title"] = df["Name"].apply(extract_title)
```

Получено **17 уникальных титулов**: Mr, Mrs, Miss, Master, Dr, Rev, Col и другие. Этот признак потенциально несёт сильный предсказательный сигнал, так как коррелирует с полом, возрастом и социальным статусом.

### 3.3 Кодирование пола

```python
sex_map = {"male": 0, "female": 1}
df["Sex"] = df["Sex"].map(sex_map)
```

### 3.4 Инжиниринг семейных признаков

```python
df["FamilySize"] = df["SibSp"] + df["Parch"] + 1
df["IsAlone"] = (df["FamilySize"] == 1).astype(int)
```

- `FamilySize` — общее число членов семьи на борту (включая самого пассажира).
- `IsAlone` — бинарный флаг: **1** если пассажир путешествовал один.

## 4. Обработка выбросов

### 4.1 Боксплот для `Fare`

```python
plt.figure(figsize=(8, 4))
sns.boxplot(x=df["Fare"])
plt.show()
```

Боксплот наглядно демонстрирует наличие большого числа точек-выбросов в правом хвосте.

### 4.2 Определение выбросов методом IQR

```python
Q1 = df["Fare"].quantile(0.25)
Q3 = df["Fare"].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
outliers_fare = df[(df["Fare"] < lower) | (df["Fare"] > upper)]
print(len(outliers_fare))  # 116
```

Метод IQR выявил **116 выбросов** по признаку `Fare` — это около 13% всех записей. Основная часть — пассажиры, заплатившие очень высокую цену (1-й класс, каюты-люкс).

### 4.3 Распределение `Age`

```python
plt.figure(figsize=(8, 4))
sns.histplot(df["Age"], kde=True)
plt.show()
```

После заполнения пропусков медианой распределение возраста приобрело выраженный пик на отметке 28 лет (эффект массового заполнения). Хвосты остаются умеренными.

### 4.4 Winsorization для `Fare`

```python
fare_low = df["Fare"].quantile(0.05)
fare_high = df["Fare"].quantile(0.95)
df["Fare"] = df["Fare"].clip(fare_low, fare_high)
```

Значения `Fare` обрезаны до диапазона [5-й; 95-й перцентиль]. Это устраняет влияние экстремальных стоимостей без удаления строк.

### 4.5 Замена экстремальных значений `Age` на 95-й перцентиль

```python
age_p95 = df["Age"].quantile(0.95)
df["Age"] = df["Age"].clip(upper=age_p95)
```

После обработки боксплот `Age` не показывает выбросов выше установленного порога.

## Заключение

### Результаты работы

В ходе выполнения лабораторной работы был проведён полный цикл предобработки данных датасета Titanic:

1. **Первичный анализ** выявил 891 запись, 12 признаков, 3 столбца с пропусками и выраженные выбросы в признаке `Fare`.

2. **Обработка пропусков** — пропуски в `Age` (19,9%) заполнены медианой (28 лет), в `Embarked` (0,2%) — модой ('S'). Для `Cabin` с 77% пропусков создан новый признак `Cabin_letter`.

3. **Трансформация данных** — создано 5 новых признаков: `Age_group`, `Title`, `FamilySize`, `IsAlone`, `Cabin_letter`; `Pclass` преобразован в строковую категорию, `Sex` — в числовой формат.

4. **Обработка выбросов** — выявлено 116 выбросов в `Fare` (13% записей); применена winsorization для `Fare` и обрезка по 95-му перцентилю для `Age`.

5. **Агрегация** подтвердила ключевые закономерности: выживаемость резко падает с понижением класса билета; женщины выживали значительно чаще мужчин во всех классах; дети 2-го класса выжили все (100%).

### Выводы

- Предобработка данных — не рутинная операция, а источник аналитических инсайтов. Уже на этапе анализа пропусков и распределений выявляются важные закономерности.
- Выбор метода заполнения пропусков влияет на последующий анализ: медиана возраста по портам посадки выровнялась именно из-за единообразного заполнения, а не из-за реального сходства возрастного состава пассажиров.
- Инжиниринг признаков (Title, FamilySize, Age_group) потенциально значительно увеличивает предсказательную силу признакового пространства для задач классификации.
- Winsorization предпочтительнее удаления выбросов, когда наблюдения правдоподобны (реально высокие цены на билеты) — она сохраняет объём выборки, устраняя влияние экстремальных значений.
